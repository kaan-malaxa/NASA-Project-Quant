The user authorized the full cross-role repair and necessary contract changes, then explicitly requested
local commits on main. This supersedes the original role-folder and branch restrictions for this repair.

## Repaired handoffs

- Mandatory original/staged/configuration/outage/polygon provenance replaces optional verification.
- Complete bootstrap replicates retain calibration uncertainty in historical outage fills.
- Both routes persist excluded-year predictions and fold training years. Agreement uses matching held-out
  predictions. The locked pooled reliability metric and the absolute yearly diagnostic are both reported.
- Fetched-window and coverage metadata distinguish covered zero NRT activity from missing inputs.
- Scoped exports preserve validated compatible other regions without their intermediates. Complete staged
  publications are checked before replacement; the manifest is last and failures restore prior bytes.
- Strict validation covers shapes, duplicate keys, finite values, uncertainty bounds, daily alignment,
  missing kinds, file hashes/bytes and safe index references.
- Complete analysis years load precomputed Python period results. Exact dates independently control daily
  totals and downloads. Anomaly comparisons keep the fixed baseline; critical weeks follow selected years.
- Yearly spatial contributions share daily sources, bounds and coverage scaling with regional series.
  Maps and AOI summaries sum them; the raw monthly CSV remains a compatibility download.
- Chart/detail ranks share the baseline population. Low-activity thresholds use exported configuration
  and the selected lens units. Display longitude wrapping retains the analysis polygon unchanged.

- `data/FIRMS_world/`: all 48 all-country archives as 10,095 lossless zstd Parquet files (7.8 GB for 43.5 GB of

- `pipeline/config/world_regions.yaml` (generated by `pipeline.ingest.world_regions`): 235 country regions on
  Natural Earth map-unit outlines. `regions.yaml`, `science.yaml` and the `us` inputs are unchanged, and the
  shared publication fingerprint excludes world regions, so the published `us` site stays valid.
- Download, clean, grid, harmonize and the runner accept world regions. World coverage uses global daily counts
  (SD-08). `--all-regions` still means core regions; `--world` adds every country.
- Publication: by owner decision, world countries are verified end to end in an isolated output folder and are
  not yet published to `web/public/data/`. See `docs/world_data.md`.
